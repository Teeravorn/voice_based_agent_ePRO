หัวข้องานวิจัย Thesis ป.โท จะทำเกี่ยวกับ Conversational Agent for PROM คือ ให้ AI ทำหน้าที่พูดคุยกับผู้ป่วยเพื่อสอบถามติดตามผลการรักษา

* สักษณะงาน
   * AI จะทำการพูดคุยกับผู้ป่วยโดยคำถามจะเป็นตาม แบบฟอร์ม ePRO (functional score) ที่หมอใช้อยู่แล้ว ซึ่งภายในจะมีคำถามสำหรับการประเมินอยู่
   * เมื่อผู้ป่วยตอบกลับมา ต้องทำการ map อาการของผู้ป่วย ให้เข้ากับแบบฟอร์ม ซึ่งคำถามแต่ละข้อจะมีคะแนนตามอาการของผู้ป่วย โดยแต่ละคะแนนจะมีคำอธิบายลักษณะของอาการ เช่น ไม่มีอาการปวดแล้ว ก็อาจจะเป็น 4 หรือ 5, ปวดนิดหน่อย ก็อาจจะ 3 คะแนน
   * ทำระบบให้เป็นพูดคุยโดต้ตอบแบบเสียง และมีภาพประกอบเพื่อให้ผู้ป่วยเห็นภาพชัดเจนขึ้น
   * รัน model บน local server เพื่อ privacy
   * ข้อมูลเป็นการเก็บใหม่ คือ develop ระบบเสร็จ ทดลองเอาไปใช้กับผู้ป่วยเลย ไม่มี data PROM ที่มีเคยทำไว้ให้
* Idea ที่คิดไว้
   * ในส่วนของ audios (TTS และ ASR) เราจะไม่ focus จะใช้อันที่มีอยู่แล้ว และจะนับว่าเป็น limitation ของงาน
      * ASR : Typhoon Whisper Turbo
      * การถามคำถามจะเล่นเสียงที่ Pre-render ไว้ เพื่อให้ถามคำถามได้ตรงเป๊ะ และเหมือนกันทุกครั้ง
   * แบบฟอร์มที่จะให้ Agent เอาไปใช้จะถูกแปลงให้เป็น JSON ที่มีคำถาม และ ordinal ของคำตอบ ของแต่ละคำภามเช่น 1 ไม่ปวด - 5 ปวดมาก
   * ในฝั่ง Backend จะประกอบด้วย
   * ตัว Dialogue manager ที่คอยคุม state ของคำถาม เป็น state machine เพื่อให้ระบบรู้ว่า ตอนนี้ตัวเองอยู่คำถามไหน
   * ตัว option extractor ที่เป็นตัว map คำตอบให้เป็นคะแนนstate ของงานในตอนนี้
      * ใช้ engine/ vLLM ในการรัน QWEN3-4B / ใช้ WangchanBERTa
      * กำลังคิดอยู่ว่าถ้าใช้ WangchanBERTa ที่ ผ่าน fine-tuned แล้ว เป็นตัว map คำตอบ แล้ว LLM จะต้องใช้ไหม และใช้ทำอะไร
   * อาจารย์หมอได้เลือกแบบฟอร์มให้มา 3 ฟอร์ม
      * DASH (Disabilities of the Arm, Shoulder and Hand) -> ให้ไฟล์ตัวอย่างของฟอร์มไปด้วย
      * Toronto Extremity Salvage Score (TESS) for upper extremity
      * Toronto Extremity Salvage Score (TESS) for lower extremity
   * ได้คุยกับอาจารย์หมอ และอาจารย์ที่ปรึกษาแล้ว การ evaluation ที่อาจารย์หมอเสนอมา จะเป็นเอาผลลัพธ์ที่ AI ประเมินมาเทียบกับของพยาบาล เพื่อดูว่าประเมินได้ใกล้เคียงกับของพยาบาลไหม
